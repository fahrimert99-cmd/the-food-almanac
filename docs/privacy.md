# Privacy Policy — The Food Almanac publishing tool

Last updated: 22 October 2026

The Food Almanac publishing tool is a private automation used only by the owner of the YouTube channel
The Food Almanac (@FoodAlmanacTV) to publish the channel's own short videos to the owner's own social media
accounts (TikTok, Instagram, Facebook, Pinterest, X).

- **What we access:** With the account owner's permission, the tool uses the TikTok Content Posting API and Login Kit
  to read basic account information (display name, open ID) and to upload videos to that same account.
- **What we store:** Only the access and refresh tokens needed to publish, stored encrypted. No other user data is
  collected, sold or shared.
- **Other users:** The tool does not access or store data about any other TikTok users.
- **Deletion:** The owner can revoke access at any time in TikTok settings (Security → Manage app permissions); the
  stored tokens are then deleted.
