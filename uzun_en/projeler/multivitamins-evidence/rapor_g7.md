- **47** (2. madde): şişe + bardak + tablet. Vuruşlar: "2" rozeti → STANDARD DOSE başlığı + şişe/tablet etiketleri (COSMOS notu) → sağda çarpı ikonu + MEGA-DOSE SINGLE PILLS + doktor notu. Kusur yok.
- **48** (3. madde): deney tüpü + defter. Vuruşlar: "3" rozeti → üstte B12 + VITAMIN D → BLOOD TEST etiketi (tüp) → DOCTOR PICKS DOSE (defter). Kusur yok.
- **49** (4. madde): eczacı tezgâhı. Vuruşlar: "4" rozeti → TELL YOUR PHARMACIST → sol sütunda VITAMIN K etiketi → CAN AFFECT → WARFARIN → KEEP THE AMOUNT STEADY. Kusur yok.
- **50** (5. madde): fidan + şişe. Vuruşlar: "5" rozeti → sağda KEEP EXPECTATIONS MODEST → SMALL EXTRA / NOT A MEMORY PLAN etiketleri (şişe) + AVERAGE MEMORY GAIN: SMALL notu. Kusur yok.
- **51** (güvenlik): masa solda, sağ sütunda SAFETY FIRST başlığı ve sırayla gelen kontrol listesi (warfarin, böbrek hastalığı, çok ilaç, belirsiz içerik → doktor/eczacı). PILL ORGANIZER etiketi. Kusur yok.
- **52** (RECAP kartı): `BolumKarti` + 47/50/51'den 3 temiz 4:3 kırpım. Ek öğe yok (sahne 1,9 sn).
- **53** (özet): sol panelde 3 madde (kalp: önleme yok / kanser-katarakt: ılımlı / hafıza: hafif iyileşme), sağda IN MALE DOCTORS ve IN COSMOS hapları. Kusur: sağdaki kalp-göz çizimi kâğıt rengi yamayla gizlendi (son karede iz yok).
- **54** (sınırlar): sol panelde 3 madde (küçük kazanım, çoğunlukla non-Hispanic beyaz yetişkinler, yaşlı erkek çalışması: bulgu yok) → sağ panelde EVIDENCE STILL INSUFFICIENT. Kusur: alt kenardaki sahte imza satırları kâğıt rengi şeritle örtüldü. Geçişte (7 sn) sol liste solarken kısa süre görüntü üstünde silik görünür; kabul edilebilir.
