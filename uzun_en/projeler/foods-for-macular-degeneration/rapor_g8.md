# Rapor — grup 8 (sahne 56–61)

- **56** Telefon + takvim + ıspanak kasesi. Vuruşlar: "VISION CHANGES?" → "BLURRED OR DIM SPOTS" başlığı, takvime "BOOK AN EYE EXAM" etiketi, kaseye "NOT A NEW DIET" etiketi. Takvimdeki küçük anlamsız rakamlar görselde kaldı (çok küçük, gizlenmedi).
- **57** Bölüm kartı (RECAP): 58/59/60 görsellerinden 4:3 kırpımlar, "QUICK RECAP" hapı.
- **58** Kase + yumurta + büyüteç. Vuruşlar: LUTEIN / ZEAXANTHIN / MACULAR DEGENERATION etiketleri, –40% rozeti, sonda "ASSOCIATION, NOT PROOF" başlığı (sol panelle).
- **59** Şişe + ıspanak + gözlük. Vuruşlar: AREDS2 etiketi, onaylı liste (intermediate / advanced in one eye), "NOT FOR HEALTHY EYES" etiketi, çarpılı liste (beta-carotene dropped / lung cancer risk).
- **60** Tabak + pencere. Vuruşlar: SPINACH / EGGS / A LITTLE FAT etiketleri, "LUTEIN + ZEAXANTHIN" başlığı, ardından "DILATED EYE EXAM" + not. Pencere camındaki çatlak çizgiler kâğıt rengi geçişle soluklaştırıldı (tam gizlenmedi, çok silik kaldı). Görselde kale yok; "kale" için etiket konmadı.
- **61** Kapanış kartı: 55/48/58 kırpımları, "SUBSCRIBE" → "FOR EDUCATION ONLY" hapı.
- Hiçbir görsel yeniden üretilmedi. Kütüphane hatası bulunmadı.
